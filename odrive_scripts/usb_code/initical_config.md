
## Setting Limits for safekeeping of motor and driver

### Current

    odrv0.axis0.motor.config.current_lim = 30

The above command sets the current threshold to 30A. Note that this current threshold refers to the Q-axis current, not the supply current.
This threshold directly limits the output torque. For 6010-8, please do not set this threshold above 50A!

### Velocity Limit

    odrv0.axis0.controller.config.vel_limit = 30

The system has a global speed limit, which is limited to 30 turn/s (revolutions per second). Note that pure moment is the default rule.
This speed limit does not work in mode, but can be enabled by turning on the switch described below

    odrv0.axis0.controller.config.enable_torque_mode_vel_limit = 1


### Calibrate Current
This current is 5A by default, which does not need to be modified by default, but if the user's supply current is small, this value can be reduced, otherwise a low voltage alarm will appear during calibration.

    odrv0.axis0.motor.config.calibration_current = 2


##  Set key hardware parameters

###  Maximum discharge/charge current

The discharge current refers to the forward current that the power supply supplies to the driver and motor, and the charging current refers to the current flowing into the power supply in the opposite direction. Both
The value is related to the power supply, please set it to an appropriate value to avoid the voltage being pulled down due to the power supply being unable to discharge, or being back electromotive damage. Note, however, that if you set these two values to a value with a small absolute value, it is easy to generate an alarm

    odrv0.config.dc_max_negative_current
    odrv0.config.dc_max_positive_current



###  Number of pole pairs
The number of pole pairs is the number of poles in the rotor of the motor divided by 2. The user must set this value correctly for the calibration to be successful, otherwise it will cause a calibration alarm.

    odrv0.axis0.motor.config.pole_pairs = number of poles in the rotor/2

### Torque Constant
The torque constant is the torque generated by the motor divided by the Q-axis current, and its relationship with the Kv value of the motor is : 8.27.

    odrv0.axis0.motor.config.torque_constant

Whether the torque constant is correct or not does not affect the operation of the motor, but it will affect the unit conversion of the value entered by the user when doing torque control.
If you want to control the moment in units A instead of Nm, simply set this value to 1.

### Temprature Sensing
Both the driver board and the motor are equipped with NTC temperature sensors, and if enabled, the driver controls the output current (torque) according to the temperature to protect the driver and the motor.

#### Motor temperature protection
    odrv0.axis0.motor.motor_thermistor.config.enabled = 1
    odrv0.axis0.motor.motor_thermistor.config.temp_limit_lower = 20
    odrv0.axis0.motor.motor_thermistor.config.temp_limit_upper = 100

####  Driver board temperature protection
    odrv0.axis0.motor.fet_thermistor.config.enabled = 1
    odrv0.axis0.motor.fet_thermistor.config.temp_limit_lower = 20
    odrv0.axis0.motor.fet_thermistor.config.temp_limit_upper = 100

#### Get the temperature
    odrv0.axis0.motor.motor_thermistor.temperature
    odrv0.axis0.motor.fet_thermistor.temperature


## PID tuning

    odrv0.axis0.controller.config.pos_gain=20.0
    odrv0.axis0.controller.config.vel_gain=0.16
    odrv0.axis0.controller.config.vel_integrator_gain=0.32

The following process can provide a reference for users to adjust PID parameters:

1. Set the initial value of the PID
2. Set the vel_integrator_gain to 0

        odrv0.axis0.controller.config.vel_integrator_gain=0
3. Adjustment vel_gain Method:
    1. Rotate the motor with the speed control mode, if the rotation is not smooth, there is shaking or vibration, reduce the vel_gain, straight to turn smoothly.
    2. Then, increase the vel_gain by about 30% each time until you notice noticeable jitter
    3. In this case, reduce the vel_gain by about 50% to stabilize it
4. Adjustment pos_gain Method:
    1. Try to turn the motor with the position mode, if the rotation is not smooth, there is a pull or vibration, reduce the pos_gain, straight to turn smoothly
    2. Then, increase the pos_gain by about 30% at a time, until there is a significant overshoot in the position control (i.e., each bit Set the control motor to exceed the target position and then oscillate back to the target position)
    3. Then, gradually reduce the pos_gain until the overshoot disappears
5. After the above 4 adjustments, you can set the vel_integrator_gain to :
    
        0.5*bandwidth*vel_gain
    , where bandwidth is the bandwidth that the system controls. 
    
     - What is control bandwidth? 
        
        For example, from the user setting the target position, to the motor reality If the time to reach the target position is 10ms, the control bandwidth is 100Hz

            vel_integrator_gain=0.5*100*vel_gain.

In the process of parameter tuning, it is recommended to use the graphical means in 3.1.7 to view the effect of parameter tuning in real time to avoid the error of visual perception
Difference.



# Power-on calibration

The first time you use a micromotor, you need to calibrate the motor and encoder. Before calibration, please fix the motor,
Or hold it tightly by hand, the output shaft is unloaded, and the calibration process is as follows:

    odrv0.axis0.requested_state = AXIS_STATE_MOTOR_CALIBRATION
    dump_errors(odrv0)
    odrv0.axis0.requested_state = AXIS_STATE_ENCODER_OFFSET_CALIBRATION
    dump_errors(odrv0)
    odrv0.axis0.motor.config.pre_calibrated = 1
    odrv0.axis0.encoder.config.pre_calibrated = 1
    odrv0.save_configuration()

The step-by-step explanation is as follows : 

1. Self-identification of motor parameters

    Measure the phase resistance and phase inductance of the motor, and a sharp "beep" sound is heard. The measurement results of phase resistance and phase inductance can be viewed using the following commands : 

        odrv0.axis0.motor.config.phase_resistance
        odrv0.axis0.motor.config.phase_inductance

2. Check the error code

    Check the system error code after the first step, if there is any red error code, you need to restart the motor and try again.
    Or report after-sales.

3. Encoder calibration

    Calibration of the encoder, including the alignment of the mounting angle of the encoder with the mechanical angle of the motor, as well as the calibration of the encoder itself.

    During this calibration, the motor slowly rotates one angle forward and then one angle again. If it stops after only turning forward, it is explained
    If there is an error, please check the error code in step 4

4. Check the error code

    In the third step, after the encoder is calibrated, look at the system's error codes. The mistakes that usually occur are: ERROR_CPR_POLEPAIRS_MISMATCH, it means that the CPR of the encoder is set incorrectly, or the number of pole pairs of the motor is set incorrectly, please check/set it by the following command:

        odrv0.axis0.motor.config.pole_pairs
        odrv0.axis0.encoder.config.cpr


5. Write the motor calibration success flag

6. Write the encoder calibration success flag

7. Save the calibration results and reboot

    Be sure to store any parameter modifications after they have been modified, otherwise the changes will be invalidated after a power outage or reboot. The drive will reboot after the parameters are saved.

        odrv0.save_configuration()

# Backup and Restore Parameters

1. Parameters Backup

        odrivetool backup-config "d:/test.json"


    "d:test.json" is the save path and file name that can be freely modified.

2. Restore Parameters from backup file

        odrivetool restore-config "d:/test.json"
